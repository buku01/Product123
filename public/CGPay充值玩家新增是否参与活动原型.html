活动参与选择及详情跳转

2026-10-30

在原充值奖励规则中新增玩家参与方式开关和活动详情地址。原型使用红色圆角框、浅蓝底及“新功能”标签标出本次新增或调整位置，仅用于需求评审。

一、功能位置与说明

标记位置 / 配置项需求说明
①后台 → 活动中心 → CGPay充值奖励 → 编辑活动规则
玩家选择参与活动		新增开关，默认关闭；整个活动关闭时不显示此配置。活动开启且本开关关闭时前台不展示参与选择，符合活动条件的充值沿用自动笔笔送规则；开启时显示参与选项，默认选中后台配置的选项，玩家可自行切换。
②同一规则弹窗
活动详情地址		新增非必填链接配置，允许有效的 http:// 或 https:// 地址。配置后前台点击“详情”在新标签页打开；为空时展示原活动详情弹窗。无效地址提示错误并阻止保存。
③前台充值页 → 金额输入下方、确认存款上方
是否参与活动		仅在后台开关开启时展示。“不参与活动”与活动卡片为互斥单选，初始配置默认“不参与活动”，后台可改为默认“参与活动”。最终选中参与时，按原活动规则判断是否赠送；不参与则正常充值、不进入该活动赠送流程。
④前台活动卡片
详情入口		详情入口沿用原位置，新增后台地址联动。点击仅查看详情，不改变玩家当前的参与选择。活动卡片隐藏时，该详情入口随之隐藏。

二、开关行为

后台开关前台展示参与及赠送逻辑
活动关闭隐藏参与选择区域自动关闭并隐藏玩家选择开关，不参与活动赠送。
活动开启 / 选择开关关闭（默认）隐藏“是否参与活动”区域自动参与，按原笔笔送规则判断及发放。
开启 · 默认状态显示区域，选中后台配置的默认选项以最终选中项为准：参与则按原规则判断赠送，不参与则不进入赠送流程。
开启 · 玩家选择参与活动卡片选中，“不参与活动”取消选中根据原活动门槛、比例、奖励上限、资格和流水要求执行。

三、保存与交互要求

  1. 后台点击“保存”后，新开关及详情地址同时生效；取消或关闭弹窗不应用本次修改。
  2. 后台开启开关后，前台按已保存的默认参与选项选中，玩家可切换；玩家选择开关关闭后，在活动开启的前提下恢复自动参与；活动关闭则自动关闭玩家选择开关且不参与赠送。重新开启活动时，玩家选择开关保持关闭，需手动开启后才按默认配置选中。
  3. 详情地址两端空格在保存时清理；允许清空地址，保存后恢复原详情弹窗。
  4. 玩家选项不受点击“详情”影响；提交充值时应使用当前有效开关及参与选择，判定是否进入该活动赠送流程。
  5. 保留原活动的门槛、首充次数、赠送比例、奖励上限、测试UID、黑名单和流水要求。选择参与不代表必定获得奖励。

四、验收要点

  • 活动开启且玩家选择开关关闭：不显示参与选项，符合条件的充值自动按原规则参与笔笔送。活动关闭：玩家选择开关自动关闭并隐藏，充值不参与活动赠送。
  • 开启后：默认参与与默认不参与两种配置均生效；玩家可切换，提交信息与最终选择一致。
  • 保存有效详情链接：点击“详情”打开配置地址，且不切换参与状态。
  • 清空详情地址：恢复详情弹窗；无效地址无法保存。
  • 取消修改：开关及地址均保持已保存状态。

五、活动状态联动、默认配置与日志需求

  1. 活动关闭联动：关闭活动时自动关闭并隐藏“玩家选择参与活动”及其默认选项配置，保存后同时生效；前台隐藏参与选项且不进入活动赠送流程。再次开启活动时，玩家选择开关保持关闭，需手动开启。取消或关闭弹窗不改变已保存配置。
  2. 默认参与选项：在“编辑活动规则”中提供“参与活动 / 不参与活动”配置，初始为“不参与活动”；只在参与开关开启时生效。保存后应用，取消不生效。默认参与也不代表必定获得奖励，仍需满足原活动资格。
  3. 日志触发（仅需求说明）：活动及玩家选择开关均开启时，玩家以“不参与活动”提交充值即记录日志，包括默认不参与直接提交、从参与切换到不参与再提交两种情况。仅切换选项或查看详情不记录订单日志；活动关闭、玩家选择开关关闭或最终选择参与时，不记录此类不参与日志。
  4. 日志字段：记录时间、UID、用户名、充值订单ID、活动及充值通道、金额、提交时开关状态、默认参与配置、最终参与选择、选择来源与活动处理结果。保存提交时的配置快照，后续修改配置不覆盖历史记录。
  5. 日志用途：后台须持久化记录，支持按UID / 用户名和充值订单ID关联查询，方便排查未赠送原因；避免重复处理同一订单时重复写入。本次原型仅说明日志需求，不新增日志页面或演示记录功能。
  6. 验收：默认参与时可主动切换不参与并生成记录；默认不参与直接提交也生成记录。参与及自动笔笔送不生成不参与日志，取消后台修改不改变默认选项。

原型操作：在“后台管理”点击“编辑活动规则”查看新增参与开关和详情地址；开启并保存后，在同页“前台充值页”查看新增参与选项和详情入口。此单文件用于交互演示，刷新后恢复初始配置。
