后台需求说明

1. 入口与配置范围

  • 入口：内容管理 → 关键词自动回复配置 → 顶部“自动推送卡片管理”按钮（位于“新增关键字配置”旁）。
  • 自动推送卡片管理作为页面配置功能，不单独设置左侧菜单入口。提供“充值订单卡片推送一”和“充值订单卡片推送二”，两条规则独立开关、独立配置卡片。
  • 点击“卡片配置”编辑对应规则的卡片，关闭该规则后不执行该规则的自动推送。

2. 充值订单卡片推送一

  • 配置“线下充值订单交易过期剩余 X 分钟”，仅对线下充值订单，在交易过期前的指定时间推送卡片。
  • 分钟数填写大于等于 1 的整数。
  • 推送卡片需关联触发该次推送的充值订单，供前端进入对应存款订单。

3. 充值订单卡片推送二

  • 进入聊天页面时检查玩家的线下等待充值订单，存在未转账订单时判断是否允许推送。
  • 本次拟推送时间与上一次成功推送时间相差 ≥ X 分钟，才允许推送；无成功推送记录时可直接推送。
  • 按玩家记录该规则的成功推送时间，推送失败、跳过或仅检测订单不更新时间。
  • 达到间隔不会自动推送，需再次进入聊天页面触发检查。

4. 卡片配置与保存

  • 图片链接、按钮图链接、跳转分类、跳转链接全部必填；缺少任意一项时不允许保存卡片配置，并提示对应字段。
  • 跳转分类：请选择 / 小程序 / H5。小程序填写页面路径，H5 填写完整的 http:// 或 https:// 链接。
  • 卡片配置弹窗中保存后暂存修改；点击页面“保存配置”后生效。已开启的规则必须先完成卡片配置。
  • 存款订单场景需携带卡片对应的订单标识，确保点击后展示正确的订单。

原型说明：当前 HTML 仅演示配置填写、校验、本地保存及静态页面展示；实际推送、订单关联和付款确认由业务系统实现。
